## Notes (from openkanban card)

when i wrap up work in openkanban sessions on managed tickets, i always get the same questions, just asked slightly differntly. i want to standardize what we do when work is complete. we need to start by brainstorming where this goes - openkanban configuration? skill? somewhere else? - then determine how it is saved - per project? global? global with project override? - and then implement. when closing tickets out, i constantly use the same two questions: first, i say "write documentation and memories, commit everything, write a PR, push, and merge so it's picked up on the next start of openkanban, and prepare to close the session
", then, when that and all the related work is complete, i say "anything else to be done, experience to be saved, lessons to be learned before i close out this session?" ... how can we make the whole thing much much more efficient?
